## Project Overview
An autonomous cloud ecosystem executing daily market analysis on 11 assets. Orchestrated with four sequential AI agents handling technical analysis, News NLP sentiment, signal generation, and risk governance.

## Architecture
- **Agent 1:** Data Ingestion & Technical Indicator computation.
- **Agent 2:** Real-time sentiment extraction via News NLP.
- **Agent 3:** Machine learning predictive signal modeling.
- **Agent 4:** Quantitative risk assessment and capital allocation.

## Key Metrics
- **Model Accuracy:** 60.75%
- **Input Features:** 13
- **Automation Execution:** Triggered daily at 8:00 AM via AWS Lambda
