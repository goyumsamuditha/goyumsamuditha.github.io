## Project Overview
Unsupervised machine learning analysis conducted on 6,000+ physicochemical profiles to understand latent structural clusters and chemical indicators of wine quality.

## Implementation
- Implemented in R with multivariate data scaling.
- Evaluated optimal clusters using Silhouette width diagnostics.
- Constructed Hierarchical dendrogram linkages verified against Cophenetic correlation coefficients.
